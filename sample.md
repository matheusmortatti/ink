# Markdown-Term Demo

This is a **hybrid markdown editor** with Vim motions.

## Features

- Navigate with `hjkl` keys
- Edit with Vim operators: `dw`, `cw`, `yy`, `dd`
- Visual mode with `v` and `V`
- Search with `/pattern` and `n`/`N`

## Code Example

```go
func main() {
    fmt.Println("Hello, World!")
}
```

## How It Works

The document displays as **rendered markdown preview**, except the block
containing the cursor shows **raw markdown text** for editing. This is
similar to Obsidian's "live preview" mode.

Move your cursor between blocks to see the hybrid rendering in action!
