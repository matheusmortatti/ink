# ink

A terminal markdown editor with live preview and Vim motions.

Ink renders your markdown as you type — inactive blocks are beautifully styled while the block you're editing stays as raw text with syntax highlighting, inspired by Obsidian's live preview.

## Features

- **Hybrid rendering** — Rendered markdown for inactive blocks, raw text for the active block
- **Vim motions** — Normal, Insert, Visual, Visual Line, Command, and Replace modes
- **Undo/redo** — Full edit history
- **Mouse support** — Click to position cursor

## Built with

- [Bubble Tea](https://github.com/charmbracelet/bubbletea) — TUI framework
- [Glamour](https://github.com/charmbracelet/glamour) — Markdown rendering
- [Lip Gloss](https://github.com/charmbracelet/lipgloss) — Styling
- [Goldmark](https://github.com/yuin/goldmark) — Markdown parsing
